# Change EV-006

## Add ordinary name update

Add PATCH /users/{id} for changing a user's name. The request must contain exactly a valid name. Email remains immutable through this endpoint. Preserve every other current behavior and restriction.

Requirement IDs activated by this change: LD-006-name-update, LD-006-ordinary-email-immutable.
Requirement IDs retired by this change: none.
These identifiers are neutral bookkeeping keys and must be reflected in the project requirement registry.

This is the only new change for this version.
Future changes are intentionally unavailable.
