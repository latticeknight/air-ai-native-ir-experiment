# Change EV-012

## Hide deleted users

A deleted user must no longer be returned by normal GET /users/{id} lookup and must produce the same structured not_found response as an unknown user. Preserve every other current behavior and restriction.

Requirement IDs activated by this change: LD-012-deleted-user-hidden.
Requirement IDs retired by this change: none.
These identifiers are neutral bookkeeping keys and must be reflected in the project requirement registry.

This is the only new change for this version.
Future changes are intentionally unavailable.
