# Change EV-008

## Audit every email change

Every successful email change must append an audit record containing the user ID and the old and new email values. A failed email change must not append an audit record. Preserve every other current behavior and restriction.

Requirement IDs activated by this change: LD-008-email-change-audit.
Requirement IDs retired by this change: none.
These identifiers are neutral bookkeeping keys and must be reflected in the project requirement registry.

This is the only new change for this version.
Future changes are intentionally unavailable.
