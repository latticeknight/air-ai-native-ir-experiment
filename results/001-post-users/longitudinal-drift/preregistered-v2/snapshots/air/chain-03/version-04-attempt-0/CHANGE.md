# Change EV-004

## Add user lookup

Add GET /users/{id}. Return the current public user object for an existing user and a structured not_found error for an unknown user. Preserve every other current behavior and restriction.

Requirement IDs activated by this change: LD-004-user-lookup.
Requirement IDs retired by this change: none.
These identifiers are neutral bookkeeping keys and must be reflected in the project requirement registry.

This is the only new change for this version.
Future changes are intentionally unavailable.
