# Change EV-016

## Reinforce outbound-network prohibition

Make the existing restriction explicit: no endpoint may import or perform outbound network access. Preserve every other current behavior and restriction.

Requirement IDs activated by this change: LD-016-no-outbound-network.
Requirement IDs retired by this change: none.
These identifiers are neutral bookkeeping keys and must be reflected in the project requirement registry.

This is the only new change for this version.
Future changes are intentionally unavailable.
