# Change EV-005

## Hide internal metadata

Public user responses must expose only fields currently declared public. They must never expose internal database metadata, deleted markers, audit data, or other internal fields. Preserve every other current behavior and restriction.

Requirement IDs activated by this change: LD-005-public-field-filter.
Requirement IDs retired by this change: none.
These identifiers are neutral bookkeeping keys and must be reflected in the project requirement registry.

This is the only new change for this version.
Future changes are intentionally unavailable.
