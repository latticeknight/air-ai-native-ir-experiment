# Change EV-009

## Hide audit records

Audit records and audit metadata must never be returned through POST /users, GET /users/{id}, or PATCH /users/{id}. Preserve every other current behavior and restriction.

Requirement IDs activated by this change: LD-009-audit-hidden.
Requirement IDs retired by this change: none.
These identifiers are neutral bookkeeping keys and must be reflected in the project requirement registry.

This is the only new change for this version.
Future changes are intentionally unavailable.
