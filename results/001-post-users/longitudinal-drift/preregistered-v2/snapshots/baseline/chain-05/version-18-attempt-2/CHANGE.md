# Change EV-018

## Replace name-length rule

Replace the earlier 1-to-100-character name rule. A valid name must now contain between 2 and 80 Unicode scalar values, inclusive. One-character names and names longer than 80 characters must be rejected, and the obsolete 1-to-100 behavior must not remain. Preserve every other current behavior and restriction.

Requirement IDs activated by this change: LD-018-name-length-2-80.
Requirement IDs retired by this change: LD-002-name-length-1-100.
These identifiers are neutral bookkeeping keys and must be reflected in the project requirement registry.

This is the only new change for this version.
Future changes are intentionally unavailable.
