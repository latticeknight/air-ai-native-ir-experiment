# Change EV-003

## Add verification state

Add a public boolean verified field to users. Every newly created user must have verified set to false, and create responses must include that value. Preserve every other current behavior and restriction.

Requirement IDs activated by this change: LD-003-verified-default.
Requirement IDs retired by this change: none.
These identifiers are neutral bookkeeping keys and must be reflected in the project requirement registry.

This is the only new change for this version.
Future changes are intentionally unavailable.
